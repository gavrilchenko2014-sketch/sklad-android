# Склад — Android MVP

Локальное мобильное приложение для учёта складских позиций.

## Уже есть

- создание складской позиции;
- категория, единица учёта, место хранения и примечание;
- текущий остаток;
- операции «Приход» и «Выдача»;
- запрет ухода остатка ниже нуля;
- журнал операций с датой и примечанием;
- поиск по названию, категории и месту хранения;
- локальная SQLite-база;
- GitHub Actions для автоматической сборки release APK.

## Где взять APK

После push в `main` открой:

**GitHub → Actions → Build Android APK → последний успешный запуск → Artifacts → `sklad-android-apk`**

## Локальный запуск

```bash
flutter create --platforms=android --project-name sklad_bk --org ua.sklad.bk .
flutter pub get
flutter run
```
